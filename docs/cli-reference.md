## Migration

### gvm adopt

import an existing server install _(partial: `gvm adopt discover` and `finalize` work; cutover and rollback are not in this build)_

Subcommands:

- `discover` — inspect an existing server install — reads only; safe with players online
- `cutover` — switch a legacy service over to gvm _(not in this build: not in this build)_
- `rollback` — revert a cutover to the legacy service _(not in this build: not in this build)_
- `finalize` — remove the legacy unit after a cutover — refuses within 7 days without --force

Examples:

```
gvm adopt discover --unit zomboid
```

## Administration

### gvm user

manage dashboard users, invites and roles

Subcommands:

- `create` — create an owner or admin account (password + TOTP at the terminal)
- `invite` — invite an operator or viewer by single-use URL
- `list` — list dashboard users
- `show` — show one account and its grants
- `roles` — print what each role may do
- `grant` — give a user a role on one instance
- `revoke-grant` — remove a user's grant on one instance
- `disable` — disable an account and revoke its sessions and tokens
- `enable` — re-enable a disabled account
- `reset` — clear factors and revoke sessions, so the user re-enrols
- `sessions` — list live dashboard sessions
- `revoke-sessions` — revoke a user's live sessions

Examples:

```
sudo gvm user create --email you@example.com --role owner
sudo gvm user grant alice@example.com pz1 operator
sudo gvm user reset alice@example.com --totp
```

### gvm token

manage API tokens

Subcommands:

- `create` — mint an API token, shown once
- `list` — list API tokens
- `revoke` — revoke an API token by name or prefix

Examples:

```
sudo gvm token create --user you@example.com --name ci-bot --role operator --expires 90d
```

### gvm secret

set, rotate and read back instance and host secrets

Subcommands:

- `set` — set an instance or host secret from a prompt, file, pipe or --generate
- `list` — list an instance's or the host's secrets, with length and fingerprint
- `show` — print one secret's value to an interactive terminal
- `rotate` — replace an instance secret with a freshly generated password
- `show-path` — print the file a secret is (or would be) stored in

Examples:

```
printf '%s' hunter2 | sudo gvm secret set pz1 join_password
sudo gvm secret set cs2-1 gslt
sudo gvm secret set pz1 rcon_password --generate
printf '%s' "$KEY" | sudo gvm secret set --host curseforge
sudo gvm secret list pz1
sudo gvm secret list --host
sudo gvm secret show pz1 join_password
sudo gvm secret rotate pz1 rcon_password
sudo gvm secret show-path pz1 join_password
```

### gvm db

manage the datastore schema

Subcommands:

- `migrate` — apply pending schema migrations
- `status` — print the live schema version vs this binary
- `version` — print the schema version this binary requires
- `replay-spool` — insert queued spool records into the audit log
- `check-grants` — verify the web role cannot read restricted columns

Examples:

```
gvm db status
```
