### gvm stop

### gvm restart

restart an instance

### gvm status

show instance state

### gvm list

### gvm logs

### gvm ports

### gvm destroy

### gvm console

### gvm control

## Migration

### gvm adopt

import an existing server install _(partial: `gvm adopt discover` and `finalize` work; cutover and rollback are not in this build)_

Subcommands:

- `discover` — inspect an existing server install — reads only; safe with players online
- `cutover` — switch a legacy service over to gvm _(not in this build: not in this build)_
- `rollback` — revert a cutover to the legacy service _(not in this build: not in this build)_
- `finalize` — remove the legacy unit after a cutover — refuses within 7 days without --force

Examples:

```
gvm adopt discover --unit zomboid
```

## Administration

### gvm user

manage dashboard users and roles _(not in this build: dashboard users are not in this build)_

Subcommands:

- `list` — list dashboard users
- `create` — create a dashboard user
- `show` — show one user
- `set-role` — set a user's global role
- `set-password` — set a user's password
- `disable` — disable a user
- `enable` — enable a user
- `reset-totp` — clear a user's TOTP enrolment

Examples:

```
gvm user create --email ops@example.com --role operator
```

### gvm token

manage API tokens _(not in this build: API tokens are not in this build)_

Subcommands:

- `create` — mint an API token
- `list` — list API tokens
- `revoke` — revoke an API token

Examples:

```
gvm token create --name ci-bot --role operator
```

### gvm secret

manage instance secrets _(not in this build: setting instance secrets is not in this build)_

Subcommands:

- `list` — list instance secret names
- `set` — set an instance secret
- `rotate` — rotate an instance secret
- `show-path` — print where a secret is stored

### gvm audit

view audit log records _(not in this build: reading the audit log is not in this build)_

Subcommands:

- `tail` — replay the audit spool in order
- `search` — filter the audit spool

## Host

### gvm host

install gvm on this host (host init)

### gvm firewall

manage host firewall rules _(not in this build: gvm does not manage the firewall in this build)_

### gvm doctor

check the host for problems

### gvm db

manage the datastore schema

Subcommands:

- `migrate` — apply pending schema migrations
- `status` — print the live schema version vs this binary
- `version` — print the schema version this binary requires
- `replay-spool` — insert queued spool records into the audit log
- `check-grants` — verify the web role cannot read restricted columns

Examples:

```
gvm db status
```
